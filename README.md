# Site de support Nage Club

Site statique public servant d'**URL de support** et d'**URL de politique de confidentialité** pour la
fiche App Store de l'application Nage Club (`fr.nageclub.app`).

Publié par GitHub Pages : https://artek60744.github.io/nage-club-support/

| Page | Rôle |
|---|---|
| `index.html` | Page de support (URL à déclarer dans App Store Connect) |
| `faq.html` | 18 questions fréquentes |
| `confidentialite.html` | Politique de confidentialité (URL à déclarer dans App Store Connect) |
| `cgu.html` | Conditions générales d'utilisation |
| `supprimer-compte.html` | Procédure de suppression de compte (exigence Apple 5.1.1(v)) |
| `mentions-legales.html` | Éditeur, hébergement, cookies |

Aucune dépendance, aucun build : les fichiers HTML/CSS sont servis tels quels. Tous les liens sont
relatifs, le site fonctionne sous son sous-chemin GitHub Pages.
